> Interactive Developer Resume & Portfolio Generator with real-time preview, customizable themes, JSON export/import, and PDF printing support.

---

## 🌟 Features

- **⚡ Real-time Live Preview**: Instantly see changes as you switch themes or update profile JSON.
- **🎨 Multiple Themes**: Modern Tech, Minimalist Clean, and Executive Accent.
- **💾 JSON Import & Export**: Back up and restore your developer profile data seamlessly.
- **🖨️ PDF Ready**: Built-in CSS `@media print` rules formatted for clean one-page PDF output.
- **🛡️ Security**: XSS escaping and HTML sanitization built-in.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+)
- **Testing**: Node.js Native Test Runner (`node --test`)
- **CI/CD**: GitHub Actions

---

## 🚀 Quick Start

### 1. Clone & Run Locally
```bash
git clone https://github.com/msyahirmahmud/dev-resume-builder.git
cd dev-resume-builder
npm start
```
Open `http://localhost:3000` in your web browser.

### 2. Run Unit Tests
```bash
npm test
```
